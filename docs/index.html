原理

外层可滚动容器 + 内部一个总高度为 100000 × 40px 的撑高元素（spacer），滚动时用 scrollTop / itemSize 算出起止索引， 只渲染 [start, end] 区间（上下各多渲染 buffer 项防白屏），每项绝对定位到正确偏移。 所以无论多少条数据，DOM 节点始终只有几十个，滚动掉帧问题从根上解决。
